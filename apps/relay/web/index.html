Authenticated local dashboard

Open the dashboard safely.

Run the canonical launcher. It checks the daemon and protected app, creates a 60-second single-use grant, and opens an authenticated loopback browser session. 

agent-relay dashboard --web

Refresh and additional loopback tabs reuse the session while it remains active. A daemon restart, browser-session loss, 30 minutes idle, or the 8-hour absolute limit requires this command again.

Advanced recovery: connect manually

If the launcher cannot open a browser, paste both current fields from ~/.agent-relay/web-credential.json. They stay only in this page's memory.
